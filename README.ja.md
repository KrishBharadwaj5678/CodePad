# 👨‍💻 Codeパッド

**Codeパッド** は、開発体験をシンプルにするために設計された、モダンで直感的なコーディングプレイグラウンドです。コードの作成、テスト、ダウンロードを効率的に行うための、クリーンで使いやすいインターフェースを提供します。

![Codeパッド](https://github.com/KrishBharadwaj5678/CodePad/raw/main/CodePadDemo.png)

## 🚀 機能

| **機能**             | **説明**                              |
| ------------------ | ----------------------------------- |
| 🌐 **マルチ言語サポート**   | プログラミング言語を簡単に切り替えることができます。          |
| 🎨 **洗練されたUI**     | スムーズなコーディングを実現する、クリーンで直感的なインターフェース。 |
| ⚡ **リアルタイムコード編集**  | コードを書きながら即座にフィードバックを得られます。          |
| 🚀 **Streamlit対応** | Python Webアプリを迅速に構築・デプロイできます。       |
| 🧩 **シンタックスハイライト** | 色分けされた構文表示により可読性を向上させます。            |
| 🤖 **自動補完機能**      | スマートな予測候補によりコーディングを高速化します。          |
| 🎭 **カスタムテーマ**     | 美しいテーマで作業環境を自由にカスタマイズできます。          |

## 🚀 はじめに

### 1️⃣ リポジトリをクローンする

```bash
git clone https://github.com/KrishBharadwaj5678/CodePad.git
```

### 2️⃣ プロジェクトフォルダへ移動する

```bash
cd CodePad
```

### 3️⃣ 依存関係をインストールする

```bash
pip install -r requirements.txt
```

### 4️⃣ アプリケーションを実行する

```bash
streamlit run app.py
```
