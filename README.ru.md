# 👨‍💻 Кодпад

**Кодпад** это современная и интуитивно понятная среда для программирования, созданная для упрощения процесса разработки. Она предоставляет чистый и удобный интерфейс для написания, тестирования и загрузки кода.

![Кодпад](https://github.com/KrishBharadwaj5678/CodePad/raw/main/CodePadDemo.png)

## 🚀 Возможности

| **Функция**                                  | **Описание**                                                   |
| -------------------------------------------- | -------------------------------------------------------------- |
| 🌐 **Поддержка нескольких языков**           | Легко переключайтесь между языками программирования.           |
| 🎨 **Элегантный интерфейс**                  | Чистый и интуитивный интерфейс для комфортного кодинга.        |
| ⚡ **Редактирование кода в реальном времени** | Мгновенная обратная связь во время написания кода.             |
| 🚀 **Поддержка Streamlit**                   | Быстро создавайте и разворачивайте Python-веб-приложения.      |
| 🧩 **Подсветка синтаксиса**                  | Улучшает читаемость благодаря цветовой разметке.               |
| 🤖 **Автодополнение**                        | Ускоряет написание кода с помощью умных подсказок.             |
| 🎭 **Кастомные темы**                        | Настраивайте рабочее пространство под себя с красивыми темами. |

## ⚙️ Технологический стек

| **Технология**        | **Описание**                                                      |
| --------------------- | ----------------------------------------------------------------- |
| 🐍 **Питон**         | Простой и мощный язык программирования для разработки приложений. |
| 🚀 **Streamlit**      | Быстрый фреймворк для создания data-приложений и прототипов.      |
| 🖋️ **Стримлит Эйс** | Встроенный редактор кода для комфортной разработки.               |
