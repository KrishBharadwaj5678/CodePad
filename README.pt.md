# 👨‍💻 CódigoPad

**CódigoPad** é um ambiente moderno e intuitivo de programação criado para simplificar a experiência de desenvolvimento. Ele oferece uma interface limpa e amigável para escrever, testar e baixar código de forma eficiente.

![CódigoPad](https://github.com/KrishBharadwaj5678/CodePad/raw/main/CodePadDemo.png)

## 🚀 Funcionalidades

| **Funcionalidade**                    | **Descrição**                                                               |
| ------------------------------------- | --------------------------------------------------------------------------- |
| 🌐 **Suporte a Múltiplas Linguagens** | Alterne entre linguagens de programação com facilidade.                     |
| 🎨 **Interface Elegante**             | Uma interface limpa e intuitiva para uma experiência de programação fluida. |
| ⚡ **Edição de Código em Tempo Real**  | Receba feedback instantâneo enquanto escreve código.                        |
| 🚀 **Suporte ao Streamlit**           | Crie e implemente aplicações web em Python rapidamente.                     |
| 🧩 **Realce de Sintaxe**              | Melhore a legibilidade com sintaxe destacada por cores.                     |
| 🤖 **Sugestões de Autocompletar**     | Acelere a programação com sugestões inteligentes e preditivas.              |
| 🎭 **Temas Personalizados**           | Personalize seu ambiente de trabalho com belos temas.                       |

## 🚀 Primeiros Passos

### 1️⃣ Clonar o Repositório

```bash
git clone https://github.com/KrishBharadwaj5678/CodePad.git
```

### 2️⃣ Navegar até a Pasta do Projeto

```bash
cd CodePad
```

### 3️⃣ Instalar as Dependências

```bash
pip install -r requirements.txt
```

### 4️⃣ Executar a Aplicação

```bash
streamlit run app.py
```
